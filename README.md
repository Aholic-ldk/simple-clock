# 简约时钟 Simple Clock

一个**单文件、零依赖**的极简专注时钟：时钟 / 倒计时 / 秒表三合一，可换主题色与进度样式，能装到桌面离线用。

## 二、本地打开（不想联网也行）

1. 找到本项目的 `index.html` 文件。
2. **双击它**，会自动用浏览器打开。
3. 就这么简单，不需要装任何环境。

> 小提示：本地打开后如果样式看着没变，按 `Ctrl + F5` 强制刷新一下即可。

---

## 三、怎么用

- **切换三种模式**：鼠标移到屏幕上 → 右下角出现按钮，可切「时钟 / 倒计时 / 秒表」。
- **倒计时**：选好分钟数，开始 / 暂停。
- **秒表**：开始 / 归零两个按钮。
- **换颜色**：右上角点一下，弹出 9 种柔和主题色。
- **换样式**：右上角另一个按钮，可选「不显示进度 / 底部进度条 / 环形进度 / 双进度环」。
- **全屏**：按 `F` 键。
- 你的颜色、样式、时长会自动记住，下次打开还是原样。

### 键盘快捷键

| 按键 | 功能 |
|---|---|
| `空格` | 开始 / 暂停 |
| `C` / `T` / `S` | 时钟 / 倒计时 / 秒表 |
| `F` | 全屏 |
| `K` / `Y` | 打开颜色 / 样式面板 |
| `1` – `9` | 快速切换主题色 |
| `H` | 显示 / 隐藏控制面板 |

## 五、开发者：如何部署到自己账号（进阶，普通用户可跳过）

如果你想把这个时钟放到**你自己的** GitHub 上、拥有自己的在线网址：

1. 在 GitHub 新建一个仓库（例如 `my-clock`）。
2. 把本项目所有文件（`index.html`、`manifest.json`、`sw.js`、图标等）上传进去。
3. 仓库 **Settings → Pages → Source** 选 `main` 分支、`/ (root)` → 保存。
4. 等一两分钟，访问 `https://<你的用户名>.github.io/<仓库名>/` 即可。

> 本项目已部署在作者账号下，地址即上文「在线网址」。
